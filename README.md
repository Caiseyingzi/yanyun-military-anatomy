# 幽云十六州 · 冷兵器时代的军事价值

一座可操作的立体军事沙盘，解释山口、山南基地与粮源如何影响南北攻守。

**在线体验：<https://caiseyingzi.github.io/yanyun-military-anatomy/>**

## 交互

- 三个场景：守住山口、基地易手、重建纵深。
- 行军演示可暂停、播放或用滑块查看。
- 可切换农田与仓储，点击编号查看地理说明。
- 支持明暗主题、手机放大和系统减弱动态设置。
- 聚焦沙盘后，左右箭头切换场景，空格播放或暂停，数字 1–5 选择地点。

## 文件与部署

`index.html` 是默认浅色页面，`index-dark.html` 是深色入口。两者都已内嵌样式和脚本，可下载后直接在浏览器打开，无需安装依赖或运行构建。

本站通过 GitHub Pages 从 `main` 分支根目录发布。更新对应 HTML 并提交到 `main` 后，Pages 会自动重新部署。

## 史料与示意边界

地形、城池、路线和行军进度用于说明军事机制，不按比例，也不是某场战役或某一年疆域的复原。以五代至辽宋对峙为主要语境；幽云易手改变攻守条件，不意味着北宋从此无法组织防御。

- 何岁利：《[考古学视野下的燕云十六州——以鄚州城为中心](https://www.dpm.org.cn/Uploads/File/2023/07/19/u64b7500e18409.pdf)》，《故宫博物院院刊》2023 年第 7 期，第 4–5 页。
- 《[辽史》卷四十 · 地理志四 · 南京道](https://zh.wikisource.org/zh/遼史/卷40)。
- 郭志伟：《[北宋河北地区军事防御体系的构建——以“关南地之争”为中心](https://soyj.cbpt.cnki.net/portal/journal/portal/client/paper/062f6b4c4ba75bcdc8eaf88aea67b6e7)》，《宋史研究论丛》，2021 年。页面依据其公开摘要说明防御体系。
- 李诚：《[雄安新区：燕南赵北的文化高地](https://www.xiongan.gov.cn/2019-01/17/c_1210040515.htm)》，《北京日报》，中国雄安官网转载，2019-01-17。
